# 맵별 조명·공조·사운드

주행 중의 속도·접지력 사용·슬립·제동·앞차 간격을 감각 효과로 표현한다. 효과는 차량 운동 계산 결과를 읽어 동작한다.

## 설정

**EFFECTS**를 누르면 주행이 멈추고 설정창이 열린다. AMBIENT LIGHT, GENTLE CLIMATE, DRIVING AUDIO를 각각 선택한 뒤 **APPLY AND RESTART**로 적용한다.

조명·공조는 첫 실행에서 OFF, 사운드는 ON이다. 선택은 맵 전환 중 유지된다. 앱을 다시 실행하면 차량 출력은 OFF에서 시작한다.

## 맵별 효과

| 맵 | 앰비언트 조명 | 공조 | 사운드 |
|---|---|---|---|
|직선 얼음|청록 → 접지력 사용·슬립에 따른 호박색|약한 팬2, 조건 충족 시 운전석 최대1°C 냉감|가상 구동음, 노면·바람, 슬립·제동·접촉음|
|곡선 얼음|청록 → 실제 코너링 상태에 따른 호박색|약한 팬2, 조건 충족 시 냉감|구동음, 속도·슬립에 따른 주행음|
|안개 고속도로|청회색 → 30m 기준 안에서 보이는 앞차에 호박색|팬1, 설정 온도 유지|고속 노면·바람, 앞차 알림, 제동·접촉음|

안개 속 앞차 알림은 각도와 간격 조건을 만족할 때 한 번 재생한다. 조명 밝기는 SDK 지원 최댓값의20% 이내로 제한하고 색은 부드럽게 바꾼다.

## 공조 적용 조건

- 원래 공조 전원 ON, AUTO OFF.
- 속성별 지원 영역·읽기·쓰기·현재 값 확인.
- 팬은 지원 범위 안에서1~2단계.
- 냉감은 A/C ON일 때 기존 온도에서 최대1°C, 20~26°C 범위.
- A/C OFF 또는 온도 증분 확인이 어려운 경우 온도는 유지하고 팬만 적용.

공조 전원·AUTO·AC·제상·송풍 방향은 변경하지 않는다. 좌석별·연동 영역은 각 API의 capability로 확인한다.

## 상태 표시

| 표시 | 의미 |
|---|---|
|OFF|선택하지 않았거나 효과가 중단된 상태|
|APPLIED|setter 이후 getter에서 요청 적용을 확인|
|UNSUPPORTED|기능·영역 또는 적용 조건 미충족|
|ERROR|SDK 요청·읽기·쓰기 오류|
|RESTORING|앱이 소유한 설정의 원래 값 복원 중|
|SIMULATED|PC에서 표시하는 효과 프리뷰|

## 복원과 수동 조작

효과 OFF·설정창·맵 전환·주행 종료·P 해제·UX 제한·앱 이탈 때 출력을 멈추고 원래 값을 복원한다. 적용 중 수동으로 바꾼 값은 덮어쓰지 않는다. 복원이 끝나지 않은 항목은 기록을 남기고 다음 연결에서 재시도한다. 전원 차단이나 SDK 장애 중에는 장치가 응답할 수 있는 시점까지 복원이 지연될 수 있다.

사운드는 자체 합성이며 차량 마스터 음량은 변경하지 않는다. 다른 앱이 오디오 포커스를 요구하면 재생을 멈추고 포커스를 회복한 뒤 유효한 주행 상태에 맞춰 이어간다.
