# 램프 속도 관리와 시도 비교

곡선 맵은 같은 도로와 μ=0.12 조건에서 진입 속도와 제동 시점의 차이를 비교한다.

## 자동 가속

정지 상태로 시작하며 초기 가속 목표는50km/h다. 목표와 현재 속도의 차이로 구동 요청을 만들고 상한을12%로 제한한다. 브레이크를 누르면 구동 요청은0이 된다.

제동 중 목표 속도는 현재 속도를 기준으로 낮아지고 최저 목표는15km/h다. 브레이크를 놓은 뒤에도 낮아진 목표를 유지하므로 곡선 전에 속도를 줄여 진입할 수 있다. 재시작하면 초기 목표로 돌아간다. 내리막 중력과 실제 접지력 계산은 계속 적용되므로 목표 속도와 실제 속도가 항상 같지는 않다.

## 체험 순서

1. 자동 가속 상태로 곡선에 진입하며 접지력 사용량과 궤적을 관찰한다.
2. 벽 접촉 또는 주행 종료 뒤 RESTART한다.
3. 다음 시도에서는 곡선 이전에 브레이크를 사용해 속도를 낮춘다.
4. 같은 조향 조건에서 오른쪽 비교 패널을 확인한다.

## 비교 패널

| 항목 | 의미 |
|---|---|
|THIS / PREV|현재 / 직전 시도의 곡선 진입 속도|
|청록색 궤적|현재 시도|
|호박색 궤적|직전 시도|
|MAX OFFSET|도로 중심에서 벗어난 최대 거리|
|DRIVE TARGET|제동 이후 조정된 자동 가속 목표|
|WALL CONTACT / COMPLETE|벽 접촉 / 주행 완료 결과|

진입 속도는 중심선 거리160m를 통과하는 순간의 속도다. 직전 시도는 같은 앱 세션에서 비교한다. 실험 중 별도 디버그 입력이나 재생을 사용한 경우 일반 주행 비교에서 제외한다.
