# 안개 맵의 4접촉점 조향 모델

## 핸들각에서 바퀴각으로

조향비18:1로 핸들각을 중앙 전륜각에 대응한다. 핸들90°는 중앙 전륜각5°에 해당한다. 휠베이스2.7m와 윤거1.88m를 사용해 좌우 전륜의 Ackermann 각을 구한다. 곡선 안쪽 바퀴가 바깥쪽보다 많이 꺾인다.

SDK 입력은 직접 적용한다. PC의 A/D는 가상 핸들각을 최대540°/s로 움직이는 입력 컨트롤러다. 차량이 실제로 따라가는 궤적은 바퀴각에서 직접 정하지 않고 타이어 힘을 적분해 구한다.

## 접지점별 운동

현재 차체 속도(u,v), 요레이트 r, 바퀴 위치(xᵢ,yᵢ)로 접지점 속도 `(u-r·yᵢ, v+r·xᵢ)`를 계산한다. 이를 각 바퀴 축으로 회전한 뒤 종력 요청·횡력·마찰 한도를 구한다.

앞·뒤 차축의 하중과 강성은 좌우 바퀴에 절반씩 분배한다. 바퀴별 힘을 차체 좌표로 돌려 합산하고 `Σ(xᵢFyᵢ-yᵢFxᵢ)`에서 요 모멘트를 얻는다. 계산에 사용한 같은 바퀴각을 화면 표시에도 사용한다.

전체 지배방정식·파라미터·수치적분은 [차량 물리 모델](engineering/PHYSICS_MODELS.md)에 있다.

## 검사 항목

`Tests/ContactPatchChecks.cpp`는 다음을 확인한다.

- 좌우 Ackermann cot 관계.
- 원운동에서 접지점 속도와 조향 기하.
- 각 바퀴의 마찰원과 전체 힘·모멘트 합.
- 좌우 대칭과 월드 회전 불변성.
- 윤거0에서 자전거 모델로 환원.
- 전·후진 제동의 에너지 감소와 직선 제동 기준.

작은 조향각의 정상선회 비교 결과는 다음과 같다.

| 속도 | 모델 요레이트 | 독립 선형 기준 | 단위 |
|---|---:|---:|---|
|5m/s|0.00900785|0.00900826|rad/s|
|25m/s|0.0269557|0.0272879|rad/s|

이 비교는 속도를 유지하는 계산 검사 조건에서 수행했다. 일반 주행의 가속·제동 정책은 [안개 시나리오](FOG_HIGHWAY.ko.md)에 있다.

## 구현 범위

이 모델은 일반 승용차의 평면 운동을 다룬다. 정적 축하중, 단순화한 타이어 횡력과 종력 요청을 사용한다. 동적 하중 이동, 휠 잠김과 종슬립, 서스펜션·롤·피치, ABS/ESC 및 공력은 추가 모델의 범위다.

참고: [NVIDIA PhysX 차량 가이드](https://nvidia-omniverse.github.io/PhysX/physx/5.6.1/docs/Vehicles.html). 계산은 프로젝트의 자체 C++ 모델에서 수행한다.
