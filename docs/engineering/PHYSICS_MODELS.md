## 범위와 방정식

위치 X/Y, 요각 ψ, 차체 종속도 u/횡속도 v, 요레이트 r를 계산한다. SI 단위와 double을 사용하며 x는 전방, y는 좌측, 양의 조향/요각은 좌회전이다.

```
u' = Fx/m + rv              v' = Fy/m - ru
r' = Mz/Iz                 ψ' = r
X' = u cosψ - v sinψ        Y' = u sinψ + v cosψ
Fzf = mg b/(a+b)            Fzr = mg a/(a+b)
Mz = a Fyf_body - b Fyr_body
```

앞 차축 속도 (u,v+ar)를 조향각 δ의 타이어 좌표로 회전하고, 뒤는 (u,v-br)를 사용한다. 각 차축에서 아래 식을 적용한다.

```
α = atan2(v_tire, max(|u_tire|, 0.5 m/s))
L = μFz
q = Cα tan(α)/L
Fy_requested = -L(q-q|q|/3+q³/27)   (|q| < 3)
Fy_requested = -sign(q)L            (|q| >= 3)
Fx_requested = Fdrive - Fbrake tanh(u_tire/(0.1 m/s))
scale = min(1, L/hypot(Fx_requested,Fy_requested))
(Fx,Fy) = scale*(Fx_requested,Fy_requested)
```

사용자가 변경한 Fiala 형태의 횡력 근사와 종·횡력의 방사형 마찰원 투영을 사용한다. L=0이면 접지력은 0이고 요청 합력이 0이면 scale=1이다. 이전의 종력 우선 배분 방식은 대체됐다. 실제 빙판 타이어 데이터로 검증한 결합 슬립 타이어·ABS/ESC 모델은 아니다. 제동력의 tanh는 정지 부근에서 힘이 불연속적으로 반전되는 것을 완화한다. 0.5m/s 분모 정규화는 저속 슬립각 특이점과 강성을 완화한다.

## 방향과 바퀴 표현 보완

전륜 조향각 δ는 현재 차체에 대한 상대각이다. 월드 전륜 방향은 ψ+δ, 차체 중심의 월드 이동 방향은 ψ+atan2(v,u)다. 타이어 힘은 현재 접지점 속도를 바퀴 좌표로 변환해서 계산하며, 초기 월드 방향은 힘 계산의 기준이 아니다. 차체 방향과 이동 방향은 미끄러질 때 달라져야 한다. 화면의 BODY/COURSE/FRONT WHEEL 표시는 이 구분을 보여준다. 정지 상태의 COURSE는 방향을 해석할 수 없으므로 주행 중에 읽는다.

바퀴의 시각적 회전은 각 위치의 강체 속도 `(u-r*y, v+r*x)`를 해당 바퀴 축으로 투영한 속도로 적분한다. 좌우 및 앞뒤 바퀴의 속도를 구분했다. 이는 여전히 순수 굴림에 기반한 시각적 근사이며 바퀴 관성·휠스핀·종슬립 계산을 도입한 것은 아니다. 같은 상대 상태를 월드에서 1.2rad 회전시킨 궤적의 회전 불변성, 이동 방향과 전륜 방향이 같을 때의 슬립각0, 선회 안쪽/바깥쪽 접지점 속도를 검사했다.

정지 출발은 유지한다. 질량·μ·최대 구동력 요청은 그대로 두고 후륜 구동을 가상 AWD로 변경했다. 직선 포화 구동에서 기존 가속0.5232m/s²에서1.1772m/s²로 증가하며 μg를 넘지 않는다. 실제 양산차의 구동 배분 데이터가 아니다. `FrontDriveFraction=0`은 기존 후륜 구동이다. 검증 로그는 `docs/research/steering-contact-tests.log`다.

## 한계와 시각화

평면, 정적 차축 하중, 균일 노면 가정이다. 하중 이동, 휠스핀/잠김, 개별 바퀴 종슬립, 서스펜션, 경사, 충돌 충격량·반발, 점프, 롤/피치, 공력·구름저항은 현재 없다. 바퀴 회전은 시각적 표현이며 계산된 휠 회전 동역학이 아니다. 눈과 산은 주행 영역 밖의 배경이다. 실제 차량의 정확성을 재현했다고 주장하지 않는다.

## 3차로 벽 접촉 종료 규칙 (2026-10-29)

`Physics/RoadBoundary.h`는 무한 직선 벽 안쪽 y=±6.75m와 차체의 평면 직사각형 외곽을 검사한다. 반길이2.48m, 반폭1.22m인 보수적인 차체 근사이며 회전 시 횡방향 반경은 `e=|sin ψ|*2.48+|cos ψ|*1.22`다. `y-e≤-6.75` 또는 `y+e≥6.75`이면 접촉한다. 차로3×3.5m와 갓길2×1.5m, UE 레벨의 벽 안쪽 Y=±675cm가 같은 범위를 사용한다.

고정 스텝의 다음 상태가 접촉하면 직전/다음 자세 사이를40회 이분하여 최초 접촉 비율을 구하고 자세와 속도를 선형 보간한다. 해당 시간과 CSV의 마지막 샘플 시간도 부분 스텝으로 기록한다. 운동 상태를 동결하고 입력·재생·실험을 중지한 뒤 R만 새 주행을 시작한다. 이는 사용자 요청에 따른 게임 종료 규칙이며, 충격량·반발·차체 변형을 계산하는 동역학 모델이 아니다. 남은 속도는 접촉 순간의 값이며 정지한 화면에서 적분하지 않는다.

벽은 곧은 평행 벽에 한정한다. 끝점 접촉을 검사하므로 한 스텝 안에 회전하여 벽 밖에 나갔다 돌아오는 극단적 운동의 연속 충돌 검출은 보장하지 않는다. 곡선·움직이는 벽·3D 높이 충돌에는 이 모델을 사용하지 않는다. 네이티브 검사에는 중앙, 양쪽 경계,1cm 여유,90도 회전 차체 앞부분, 빠른 횡단의 접촉 위치, 이미 접촉한 상태를 포함했다. 차량 힘 계산 `VehicleModel.cpp`는 수정하지 않았다.

## 저마찰 프로파일 조정과 도로 연장 (2026-10-29)

더 빠른 주행 요청에 따라 기본 저마찰 프로파일을μ0.12→0.18로 조정했다. 구동 요청6000N은 이전에도 마찰 한도에 포화되어 엔진 힘만 높여서는 가속을 늘릴 수 없었다. 새 직선 전가속은 `a=μg=1.7658m/s²`로 기존1.1772의1.5배다. 정지 출발10초 속도는63.5688km/h(기존42.3792)다. 이는 현재 공력·구름저항 없는 모델의 결과이며 실제 타이어/차량 데이터가 아니다. μ의 증가는 제동·선회 가능 힘도 함께 바꾼다. 질량·힘 계산·시간적분·시각 위치 배속은 변경하지 않았다.

기존μ0.12는 회귀 검사에 유지하고μ0.18의 제동 분석해 비교 및10초 가속 검사를 추가했다. 도로는1→2km, 끝 제한은±495→±995m, 정지 출발점은-220→-440m로 바꿨다. 전방 사용 가능 거리는715→1435m로 약2배다. `RoadBoundary.h`의 값과 레벨 도로/벽/표식의 실제 범위를 함께 검증한다. 예전 CSV에는 기록 당시의μ값이 그대로 남는다.

## 안개 고속도로 실험 (2026-11-04)

세 번째 맵만 μ=0.8을 사용한다. NHTSA DOT HS809561(2003) §3.3.8의 건조 아스팔트 peak약0.9, sliding약0.8 중 sliding값을 기존 마찰원 모델의 유효 계수로 선택했다. 시험 조건72km/h의 특정 노면 대표값이며 일반적인 모든 타이어나100km/h 실차를 보정한 값은 아니다. 출처: https://www.nhtsa.gov/sites/nhtsa.gov/files/nhtsalvabs5.2-5.3final.pdf

기존 Fiala 횡력·종력 요청과 마찰원 포화, 차체좌표3자유도·고정 틱/RK4는 변경하지 않는다. 자동 구동 요청은 `clamp(0.5*(100/3.6-speed),0,0.5)`이며 속도를 강제로 지정하지 않는다. 움직인 뒤 제동이 입력되면 구동 요청을0으로 유지한다. 재시작만 이 상태를 해제한다. 공력/ABS/종슬립/하중 이동은 없다.

100km/h→정지의 포화 직선 제동 분석식 `v²/(2μg)`는49.1593m, 실제 동일 코어 적분은49.1594m였다(종료 속도≤0.05m/s). 반응1초 뒤 전제동은 반응거리27.7831m·제동 이후49.1594m·잔여간격23.0576m로 정지한다. 반응3초 또는 미제동은 앞차와 접촉한다. 이는 선언한100m 기준의 자동 입력 실험이며 사람의 반응 실험이 아니다.

앞차/자차는2.48×1.22m 반치수 OBB로 근사하며4개 분리축을 검사한다. 요각이 일정한 스텝은 연속 분리축 시간구간, 회전 스텝은 거리 하한을 이용한 보수적 전진으로 접촉을 찾는다. 회전 접선의 반복 한계는 접촉을 만들어내지 않고 시도 중단으로 보고한다. 충돌 충격량·반발은 계산하지 않고 최초 접촉 상태에서 게임 적분을 멈춘다. 측방 정지는 앞차 뒤 정지와 별도 결과다.

반응 기준은 범퍼 간격100m 및 전방±40도 조건이다. 기준 통과 시각은 스텝 내 선형 보간한다. 제동 입력은 해당 스텝 시작 시각으로 기록한다. 미리 제동·기준 시 제동 유지·제동 해제를 구분하며, 제동 이후 거리는 브레이크 해제에 따른 타력 구간도 포함한다. HUD와 저장 결과는 이를 명시한다. 정지/입력 단절/긴 프레임 중단 시 유효 반응 시간으로 이어 계산하지 않는다.

시각적 안개는 차량 힘을 바꾸지 않는다. UE LocalFogVolume의 radial/height coverage 결합에서 height=0이면 전체 안개가 사라지는 엔진 구현을 확인해 height mask를1000으로 포화시키고 radial0.05/반경1800m/중심x600m를 사용한다. 셰이더는 단위 구 적분 후 실제 반경(m)을 곱한다. 최종 시정은 렌더 경로·노출·대상 대비에 영향을 받으며100m의 실제 발견을 보증하지 않는다.
