# 차량 물리 모델

## 모델 구성

| 맵 | 차량 운동 | 노면 |
|---|---|---|
|직선 얼음|앞·뒤 차축을 묶은 3자유도 자전거 모델|평면, μ=0.12|
|곡선 얼음|자전거 모델 + 경사면 중력 투영·준정적 수직하중|가상 램프, μ=0.12|
|안개 고속도로|4접촉점 평면 강체 + Ackermann 조향|평면, μ=0.80|

Unreal과 독립된 C++ 코드로 힘과 상태를 계산한다. 단위는 SI, 수치형은 double을 사용한다. 차체 좌표는 x 전방·y 좌측, 양의 조향과 요각은 좌회전이다. Unreal의 좌표로 표시할 때 y 부호를 변환한다.

## 상태와 지배방정식

상태는 월드 위치 X·Y, 요각 ψ, 차체 종속도 u·횡속도 v, 요레이트 r이다.

```text
X_dot   = u cosψ - v sinψ
Y_dot   = u sinψ + v cosψ
ψ_dot   = r
u_dot   = Fx/m + r v
v_dot   = Fy/m - r u
r_dot   = Mz/Iz
```

Fx·Fy는 차체 좌표계의 합력, Mz는 무게중심에 대한 요 모멘트다. m은 질량, Iz는 요 관성이다. HUD의 종·횡가속도는 차체 기준 힘/질량이며 `u_dot`, `v_dot`의 회전좌표 항과 구분한다.

## 현재 속도로 계산하는 타이어 힘

접지점 위치가 (xᵢ,yᵢ)이면 현재 접지점의 차체 기준 속도는 다음과 같다.

```text
vx_i = u - r y_i
vy_i = v + r x_i
```

이 속도를 바퀴의 조향각 δᵢ만큼 회전해 타이어 종·횡속도를 구한다. 슬립각은 타이어 횡속도와 정규화한 종속도의 비에서 계산한다. 초기 차량 방향을 고정 기준으로 쓰지 않는다.

```text
u_t = cosδ_i vx_i + sinδ_i vy_i
v_t = -sinδ_i vx_i + cosδ_i vy_i
tanα = v_t / max(|u_t|, 0.5 m/s)
α = atan(tanα)
```

순수 횡력은 Fiala형 브러시 응답으로 근사한다. `L=μFz`, `q=Cα tanα/L`일 때:

```text
|q| < 3 : Fy_req = -L(q - q|q|/3 + q³/27)
|q| ≥ 3 : Fy_req = -sign(q)L
Fx_req = Fdrive - Fbrake tanh(u_t / 0.1 m/s)
```

종·횡력 합이 한도를 넘으면 힘 벡터를 방사형으로 줄인다.

```text
sqrt(Fx² + Fy²) ≤ μFz
```

제동과 조향이 같은 접지력 한도를 공유하므로 강한 제동 중에는 선회에 사용할 힘도 영향을 받는다. μFz가 0이면 타이어 힘은 0이다. 낮은 속도의 슬립 분모와 제동 부호는 각각 0.5m/s·0.1m/s로 정규화한다.

## 차축 하중과 요 모멘트

무게중심에서 앞·뒤 차축까지의 거리를 a·b로 두면 평지의 정적 하중은 다음과 같다.

```text
Fzf = mg b/(a+b)
Fzr = mg a/(a+b)
```

자전거 모델은 앞 차축 속도 (u,v+ar), 뒤 차축 속도 (u,v-br)를 사용한다. 앞 차축의 타이어 힘을 차체 좌표로 변환한 뒤 뒤 차축 힘과 합산한다.

```text
Mz = a Fyf_body - b Fyr_body
```

4접촉점 모델은 차축 하중·강성·구동·제동 요청을 좌우 바퀴에 분배하고 각 접지점에서 힘을 계산한다.

```text
Fx = Σ Fx_i_body
Fy = Σ Fy_i_body
Mz = Σ(x_i Fy_i_body - y_i Fx_i_body)
```

## 핸들과 전륜 조향

직선·램프의 Pleos 에뮬레이터 입력은 SDK raw 값을 ±540° 범위에서 정규화하고 전륜 최대 조향각 0.5rad에 대응한다. PC의 A/D는 이 조향 입력을 증감한다.

안개 맵은 핸들각 θ에 대해 조향비 18:1을 적용하고 중앙 등가 조향각을 ±30°로 제한한다. 휠베이스 L=2.7m, 윤거 t=1.88m에서 좌우 전륜각을 구한다.

```text
δ = clamp(θπ/(180·18), -π/6, π/6)
δFL = atan2(L sinδ, L cosδ - (t/2) sinδ)
δFR = atan2(L sinδ, L cosδ + (t/2) sinδ)
```

이 각도로 타이어 힘을 계산하고 같은 값을 바퀴 표시에 사용한다. 바퀴의 시각적 구름 회전은 접지점 종속도에 기반한 순수 굴림 근사다.

## 램프 경사

노면을 높이 함수 z=h(X,Y)로 나타내고 hX·hY로 법선과 접평면을 구한다. 법선의 수직 성분은 `nz=1/sqrt(1+hX²+hY²)`다. 수직하중 계산에는 `g·nz`를 사용하고, 접평면에 투영한 중력과 타이어 힘으로 가속도를 계산한다. 화면 높이와 차체 자세도 같은 노면 함수에서 구한다. 램프 형상은 [별도 문서](../VIRTUAL_RAMP.ko.md)에 있다.

## 시간 적분

외부 고정 시간 간격은 1/240초다. 각 간격은 0.5ms 이하의 같은 길이 구간으로 나눠 RK4로 적분한다. 렌더 프레임과 물리 시간을 분리한다. 상태가 유한한 값인지 확인한 뒤 갱신하며 계산 실패·긴 프레임 정체 시 주행을 중단한다.

## 기준 비교와 검사

직선에서 제동력이 마찰 한도에 포화되고 다른 저항을 제외하면 `a=μg`, `s=v₀²/(2μg)`다. μ=0.12의 가속 기준은 1.1772m/s²이고, 100km/h·μ=0.80의 이상 제동거리 기준은 약49.16m다. 실제 게임의 제동 이후 거리는 조향·초기 상태·제동 유지 여부와 함께 비교한다.

| 검사 코드 | 확인 대상 |
|---|---|
|`VehicleModelTests.cpp`|무마찰 운동, 직선 가속·제동, 마찰원, 수치 안정성|
|`ContactPatchChecks.cpp`|Ackermann 기하, 접지점 속도, 바퀴별 힘·모멘트, 좌우·회전 불변성|
|`RampChecks.cpp`|램프 형상, 경사면 중력과 벽 접촉|
|`FogChecks.cpp`, `FogTrafficChecks.cpp`|기준 거리, 정지 차량 접촉, 최초 접촉과 결과 분류|
